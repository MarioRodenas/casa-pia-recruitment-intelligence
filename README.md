# Casa Pia Recruitment Intelligence
Independent, unofficial recruitment analytics portfolio by Mario Rodenas Sistané.

## Run
`pip install -r requirements.txt`
`streamlit run app.py`

## Features
English, European Portuguese, Spanish; club overview, squad analysis, market scouting, positional player comparison and automatically generated player profile PDFs. Experimental position-relative weighted Recruitment Fit screening.

## Data provenance
`data/players.csv` is derived from the user-supplied `LigaNos_Base_Scouting.xlsx` (SofaScore-derived). Season, competition scope, clubs and player associations require independent verification. Do not describe this as an official Primeira Liga roster without that validation. No player photographs are used.
